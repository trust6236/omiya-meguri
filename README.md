# 金沢 お宮さんめぐり デジタル押印帳

石川県神社庁 金沢市支部の「金沢お宮さんめぐり」（31社スタンプラリー）を回るための自分用の相棒アプリ。

- 地図で31社の位置と参拝状況を確認（Googleマップ）
- 境内の近くでGPSチェックインすると日付入りでデジタル押印
- 御朱印の記録・メモ・進捗（金澤五社バッジ）も

参拝記録は各端末のブラウザ内（localStorage）にのみ保存されます。
神社の情報は石川県神社庁の公開ページに基づきます。記念品の受領には紙の台紙が必要です。
